# 이거여기 (Virtual Room Layout)

집 안 가구를 실제로 옮기기 전에 웹에서 방 구조와 가구 배치를 시험해 볼 수 있는 개인용 레이아웃 실험 도구입니다.

## ✨ 주요 기능 (Key Features)

### 🛠 2D 도면 편집 (Room Editing)
- **자유로운 방 구조**: 다각형(Polygon) 기반의 방 외곽선 생성 및 모서리 직접 편집
- **편리한 프리셋**: 직사각형, ㄱ자, 튀어나온 면, 사선 등 자주 쓰이는 방 형태 제공
- **장애물 설정**: 기둥 등 배치가 불가능한 영역 추가 및 크기 조절

### 🛋 가구 및 구조물 배치 (Furniture Placement)
- **드래그 앤 드롭**: 침대, 책상, 소파 등 다양한 가구의 직관적인 배치
- **스마트 벽면 부착**: 문과 창문을 벽면 각도에 맞춰 자동으로 부착 및 스윙 영역 표시
- **정밀한 제어**: Inspector 패널을 통한 위치, 크기, 회전각 직접 입력 및 10px/24px 스냅 기능
- **충돌 감지**: 가구 간 겹침 시 경고 표시

### 🕶 3D 미리보기 (3D Visualization)
- **실시간 3D 렌더링**: Three.js를 활용한 2D 도면의 즉각적인 3D 입체화
- **공간감 확인**: 조명 및 그림자 효과, 선택 객체 강조, 개구부(문/창문) 3D 뚫림 효과 지원

### 💾 데이터 관리 및 편의성 (Data Management & Usability)
- **버전 및 이력 관리**: 실행 취소/다시 실행(Undo/Redo) 지원 및 로컬 스토리지를 이용한 방/배치안 저장
- **다중 배치안**: 하나의 방 구조에 대해 여러 가지 가구 배치 버전을 독립적으로 저장 및 관리
- **키보드 단축키**: 가구 이동, 회전, 복제, 삭제 등 단축키를 통한 생산성 향상

## 💻 기술 스택 (Tech Stack)
- **Frontend**: React, TypeScript, Vite
- **3D Graphics**: Three.js
- **Testing**: Vitest (단위 테스트 및 마이그레이션 테스트)

## 🚀 시작하기 (Getting Started)

### 설치 및 실행
```bash
npm install
npm run dev
```

### 테스트
```bash
npm run test           # 전체 유닛 테스트
npm run test:migrations # 데이터 마이그레이션 테스트
```

### 빌드
```bash
npm run build
```
