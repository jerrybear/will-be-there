# 이거여기

이 저장소는 집 안 가구를 실제로 옮기기 전에 웹에서 방 구조와 가구 배치를 시험해보는 개인용 레이아웃 실험 도구, 이거여기를 위한 작업 공간이다.

## 현재 구현 범위
- Vite + React + TypeScript 기반 단일 페이지 앱
- 크기 조절 가능한 직사각형 방 1개
- 기본 요소 5종: 문, 창문, 침대, 책상, 소파
- 가구 추가
- 가구 선택
- 가구 드래그 이동
- 선택 가구 복제/삭제
- Undo / Redo
- 90도 회전
- 선택 가구의 위치/크기/회전 정보 표시
- 선택 가구 이름 변경
- 선택 가구의 위치/크기 직접 입력
- 문/창문 벽 부착 배치
- 문/창문 벽 방향 자동 회전
- 문 열림 방향/스윙 영역 표시
- 일반 가구 간 충돌/겹침 경고
- 줌/팬
- 방 폭/높이 직접 입력
- 스냅 없음 / 10px / 24px 그리드 단위 선택
- localStorage 기반 저장/불러오기
- 저장안 이름/메모 관리
- 현재 저장안 덮어쓰기
- 현재 저장안 변경됨 표시
- 저장안을 새 도면으로 복사 저장
- 저장안 삭제
- Reset

## 이번 단계에서 제외한 것
- 3D 미리보기
- 배치안 비교
- 태그 UI

## 실행 방법
```bash
npm install
npm run dev
```

## 빌드
```bash
npm run build
```
